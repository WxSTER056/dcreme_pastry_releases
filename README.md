# Dcreme Pastry Releases

Official release builds for Dcreme Pastry Business Management System.

## Latest Release (v1.0.0)

- **Android APK**: [dcreme_pastry.apk](https://github.com/WxSTER056/dcreme_pastry_releases/releases/download/v1.0.0/dcreme_pastry.apk)
- **Windows Desktop**: [dcreme_pastry_windows.zip](https://github.com/WxSTER056/dcreme_pastry_releases/releases/download/v1.0.0/dcreme_pastry_windows.zip)

### Features & Updates:
- **Unified Categories**: Separated Stock Categories (purchases / cost of goods sold) and Sales Categories (revenue / menu) with inline creation and default presets.
- **Recipe Management & Mentions**: Menu recipes track inventory stock usage and costing.
- **Profit & Loss Statement**: Real-time cafe financial statement with Cost of Sales, Other Operating Income, and Operating Expenses.
- **Balance Sheet Statement**: Dynamic financial position with Assets, Liabilities, and Equity.
