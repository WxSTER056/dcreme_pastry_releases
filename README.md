Official release builds for Dcreme Pastry Business Management System.

- **Android APK**: [dcreme_pastry.apk](https://github.com/WxSTER056/dcreme_pastry_releases/releases/download/v1.0.1/dcreme_pastry.apk)

### Features & Updates:
- **Profit & Loss Statement**: Ported exact Excel-style grid design from C:\TCG_SHOP with ruled borders, subtotal bands, and key summary rows.
- **Balance Sheet Statement**: Ported exact financial position layout from C:\TCG_SHOP with Assets, Liabilities, and Equity sections.
- **Expand / Collapse**: Available on every group section (Assets, Liabilities, Equity, Revenue, Cost of Goods Sold, Other Income, Expenses) with individual arrow toggles and a card-level "Expand all / Collapse all" button.
- **No Account Codes**: Account codes have been removed from statement tables; only clean account names and RM amounts are displayed.
- **Chart of Accounts**: Completely wiped from Firebase and re-seeded with the clean standard accounts from C:\TCG_SHOP.
