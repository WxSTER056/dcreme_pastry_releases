# Dcreme Pastry Releases

Official release builds for Dcreme Pastry Business Management System.

## Latest Release

- **APK (Android)**: [Download dcreme_pastry.apk](https://github.com/WxSTER056/dcreme_pastry_releases/releases/latest/download/dcreme_pastry.apk)
- **Version**: 1.0.1

### Changes in this build:
- **Profit & Loss Statement**: Ported exact Excel-style grid design from TCG_SHOP with subtotal bands, ruled borders, and key profit lines.
- **Balance Sheet Statement**: Ported exact financial position layout from TCG_SHOP with assets, liabilities, and equity sections.
- **Expand / Collapse**: Supported on every section (Assets, Liabilities, Equity, Revenue, Cost of Goods Sold, Other Income, Expenses) with individual chevrons and a global Expand/Collapse toggle.
- **Clean Display**: Account codes removed from statement rows; only account names and RM values are displayed.
- **Chart of Accounts**: Cleaned and synced with standard business accounts.
